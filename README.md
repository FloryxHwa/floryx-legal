# floryx-legal

Public legal pages for Floryx apps and games. Hosted via GitHub Pages.

## Live URLs

- Index: https://floryxhwa.github.io/floryx-legal/
- MineHex Privacy: https://floryxhwa.github.io/floryx-legal/minehex/privacy.html

## Editing

Plain HTML — no build step. Edit, commit, push. GitHub Pages redeploys in ~1 min.

When updating a policy, bump the `Last updated:` date at the top.
